Testing NVIDIA Indic Profiles with Plivo Telephony

We built a Hindi voice agent using NVIDIA Parakeet for speech-to-text and tested it with real phone calls. Here's what we found.

Parakeet RNNT 1.1B Plivo WebSocket Hindi NIM Cloud (AWS Virginia)

Findings

CategoryRatingNotes
Parakeet STT (Hindi) Good Accurate on full sentences over phone audio. Clean punctuation, handles numbers and cricket terminology well. Picks up speaker gender ("सकती" vs "सकता").
Hinglish / Code-switching Partial Gets common English words in Hindi ("प्लेयर्स", "Thank you") but not always right. "वाइड बॉल" heard as "वाइट बॉल".
ElevenLabs TTS (Hindi) Okay Correct pronunciation but flat intonation. Sounds formal, not conversational. ElevenLabs limitation, not Parakeet.
Cloud NIM Limitations Limited Batch-only (no streaming). Only Hindi on the default function ID. Tamil and Bengali require the Indic profile, available only via self-hosted NIM container.
Production Readiness With caveats STT accuracy is good enough for IVR and call center use. For a consumer voice assistant, would need streaming mode (self-hosted) and better Hindi TTS.

How We Tested

Caller speaks Hindi → Plivo telephony → Parakeet STT → Gemini 2.5 Flash → ElevenLabs TTS → Plivo telephony → Caller hears response

We built a Hindi voice agent using Plivo for telephony, NVIDIA Parakeet for speech-to-text, Gemini 2.5 Flash for conversation, and ElevenLabs for text-to-speech. A real person called in and had a conversation in Hindi. The NIM cloud gRPC API is hosted on AWS us-east-1 (Virginia). Latency numbers include the full network round-trip from Texas to Virginia. The call was recorded by Plivo.
